# 🧠 BidEase

**BidEase** is an online auction system built using the **MERN stack (MongoDB, Express, React, Node.js)**. It allows users to register, create auctions, and place bids in a secure and user-friendly environment.

---

## 📌 Features

- 👤 User authentication (sign up/login)
- 📦 Create, view, and manage auction listings
- 💰 Place bids on items in real time
- 🕒 Auction end time with automatic winner selection
- 📊 Responsive and modern UI built with React
- 🔐 Secure API endpoints using JWT (JSON Web Tokens)

---

## 🚀 Tech Stack

| Frontend  | Backend  | Database | Other Tools |
|-----------|----------|----------|-------------|
| React     | Express  | MongoDB  | Mongoose, JWT, Axios |
| Tailwind/MUI | Node.js   |         | Dotenv, Nodemon, Bcrypt |
